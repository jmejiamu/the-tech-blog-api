# DEP-001 — Vulnerable Third-Party Dependencies

**Project:** the-tech-blog-api  
**Category:** OWASP A06:2021 — Vulnerable and Outdated Components  
**Status:** Open — Investigation Required  
**Severity:** Critical (highest reported dependency severity)  
**Tool:** npm audit

## Description

A dependency security scan identified 43 vulnerable package entries in the Node.js backend dependency tree.

## Scan Results

| Severity  |  Count |
| --------- | -----: |
| Critical  |      3 |
| High      |     26 |
| Moderate  |     10 |
| Low       |      4 |
| **Total** | **43** |

## Notable Affected Dependencies

- jsonwebtoken — High
- knex — High
- multer — High
- express — High
- body-parser — High
- pg — High
- bcrypt — High

Critical-severity transitive dependencies include minimist, proxy-addr, and tar.

## Security Impact

The reported advisories include risks involving authentication, SQL injection, denial of service, and other dependency weaknesses.

Actual exploitability within the application has not yet been verified.

## Evidence

See `security-audit/evidence/npm-audit-before.json`.

## Recommended Remediation

1. Identify the installed vulnerable versions.
2. Review the relevant security advisories.
3. Determine whether affected functionality is reachable.
4. Upgrade or replace vulnerable dependencies.
5. Run application regression and security tests.
6. Repeat npm audit and compare results.
